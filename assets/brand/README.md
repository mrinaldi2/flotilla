# Flotilla brand assets

The source of truth for the Flotilla logo and app icons. Every shape is
defined in code in `make_icons.py`, so the icons can be rebuilt exactly.

| file | what |
|---|---|
| `icon-macos.svg`, `icon-macos-1024.png` | macOS app icon: Apple rounded square with standard margins, transparent outside |
| `icon-tight.svg`, `icon-tight-1024.png` | the same mark on a rounded square filling the canvas, for Windows and the web |
| `icon-ios.svg` | iOS icon (full-bleed square); the iPhone app lives in its own repository |
| `mark-512.png` | the bare mark, transparent |
| `wordmark-light.png`, `wordmark-dark.png` | mark plus "Flotilla"; light is for light backgrounds |

Colours: sand `#ECDDBC`, coral `#F14D41`, navy `#0C3062`.

## Regenerating

`make_icons.py` needs Pillow. It writes the icons and favicons into the
folder it is given:

```sh
python3 -m venv /tmp/brand && /tmp/brand/bin/pip install pillow
/tmp/brand/bin/python assets/brand/make_icons.py /tmp/flotilla-icons
```

Then copy what changed back here, and regenerate the products' icons:

- **Desktop app** (`apps/desktop/src-tauri/icons`): from the repository root,
  `pnpm --dir apps/desktop tauri icon ../../assets/brand/icon-macos-1024.png`
  for the macOS `.icns` and the PNGs, then the Windows icons from the tight
  variant, whose margins suit the taskbar:
  `pnpm --dir apps/desktop tauri icon ../../assets/brand/icon-tight-1024.png -o /tmp/tight`
  and copy `icon.ico` and the `Square*Logo.png`/`StoreLogo.png` files from
  `/tmp/tight` into `apps/desktop/src-tauri/icons`.
- **Marketing site** (`apps/marketing/public`): `favicon-{16,32,48,180,192,512}.png`
  from the generator's output, `favicon.svg` from `icon-tight.svg`, and
  `images/wordmark-{light,dark}.png` from here.

The wordmarks are not generated by the script; they are kept as delivered.
